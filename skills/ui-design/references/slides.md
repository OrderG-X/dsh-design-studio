# 幻灯片（kind: slides）

## 画幅

- 1280×720（16:9）。一页一个 HTML 文件（`01-cover.html`、`02-problem.html` …），放同一目录，画布上按顺序排开就是整套幻灯片。
- `html, body` 宽高写死 1280×720，`overflow: hidden`。四边安全区 64px。

## 原则

- **一页一个观点**：标题就是结论（「转化率提升了 38%」，不是「数据分析」）。
- **字要大**：标题 44–56px，正文 24–28px，注释 16–18px；一页正文不超过 6 行。
- **少即是多**：能用一张图、一个大数字、一个对比说清楚的，不写段落。
- **版式统一**：所有页的标题位置、边距、页码、Logo 位置一致；用 3–4 种版式轮换：封面、章节页、标题 + 要点、大数字、左图右文、对比（两栏）、引用、结尾。
- **数据页**：图表用 SVG 画；只标关键数据，突出一根柱子 / 一条线（主色），其余灰色；图表标题就是结论。
- **颜色**：深底或浅底选一种贯穿全套；主色只用来强调。

## 常见一套

封面（标题 + 副标题 + 讲者 / 日期）→ 目录 → 问题 → 方案 → 关键数据 → 案例 → 计划 / 时间线 → 总结 → 致谢 / 联系方式。
