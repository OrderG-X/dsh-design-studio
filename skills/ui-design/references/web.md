# 网页（kind: web）

## 画幅和布局

- 按 1280–1440 宽设计，内容区最大宽度 1120–1200px 居中，两侧留白；用 12 栏网格（栏间距 24px）。
- 一定要自适应：至少在 390 宽（手机）下也不破。用 `clamp()` 做流式字号（如 `font-size: clamp(32px, 5vw, 56px)`），`grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))` 做卡片网格，组件内部用容器查询 `@container`。
- 首屏（上方 800px）讲清楚三件事：这是什么、对我有什么用、下一步点哪。

## 常见页面结构

- **落地页**：导航（Logo + 3–5 个链接 + 一个主按钮）→ 首屏（大标题 ≤ 2 行 + 一句副标题 + 主次两个按钮 + 产品图 / 插画）→ 社会证明（客户 Logo、数字）→ 功能（别都做成三栏卡片：可以左右交替、Bento 网格、大图配要点）→ 评价 → 价格 → 常见问题 → 收尾行动号召 → 页脚。
- **后台 / 仪表盘**：左侧导航 240px（图标 + 文字，当前项高亮），顶部栏（搜索、通知、头像），内容区先放关键数字卡片（大数字 + 环比），再放图表和表格。表格：行高 48–56，数字右对齐用等宽数字（`font-variant-numeric: tabular-nums`），表头浅色小字。
- **文档 / 博客**：正文栏 680–720px，左侧目录，右侧本页导航；代码块等宽字体、浅色背景。

## 细节

- 导航高 64–72px，滚动后加背景和细分割线。
- 按钮高 40–48px，左右内边距 16–24px；主按钮实色，次按钮描边或浅底。
- 链接要能看出是链接（颜色或下划线），悬停有变化。
- 深色模式：用 `prefers-color-scheme` 切 `tokens.css` 里的同一组变量，不要写两套样式。
- 不要整页都是一种卡片；区块之间用背景色深浅变化分节，比到处画线好看。
