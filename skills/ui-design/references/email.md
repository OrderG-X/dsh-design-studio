# 邮件（kind: email）

邮件客户端（Outlook、Gmail、各种手机邮件）对 CSS 支持很差，规则和网页不一样：

## 结构

- 内容宽 600px，外层一个占满宽度的背景表格，里面一个 600px 居中的表格。**用 `<table>` 布局**，不要用 flex / grid。
- 样式写成**行内样式**（`style="…"`）；`<style>` 里只放媒体查询（手机下改成 100% 宽）等可选增强。
- 不要 JavaScript、不要外部字体依赖（可以写 web font，但要有 `Arial, "PingFang SC", "Microsoft YaHei", sans-serif` 兜底）、不要背景图承载关键信息。
- 按钮用带背景色的表格单元格 + 链接（「防弹按钮」），高 44–48。

## 版式

- 顶部：Logo + 一句预览文字（隐藏的 preheader）。
- 主体：一个主标题、一张主图（带 alt）、两三段短文字、**一个**主按钮。
- 底部：灰色小字的公司信息、退订链接。
- 字号：标题 24–28，正文 16，行高 1.6；颜色对比要够，很多人在手机深色模式下看。
