# 套外框（`framed`）和做外框

有些界面长在别人的「外框」里：浏览器插件的弹窗、某个软件的侧栏、某个平台的卡片位。外框不归你设计，但很影响整体观感，所以每屏都带上外框，**你只设计槽位（`data-slot`）里面**。

外框放在用户的**外框库**（`~/.dsh/design-frames/<id>/`，技能末尾「外框库」列着库里有哪些）。DSH 桌面端的外框是自带的，见 `references/dshplugin.md`，不在这里。

## 用外框

用户点名了外框（消息里写「外框：名字（id）」），或者库里正好有合适的：

1. **复制**：用复制命令（`cp`）把外框目录里的样式文件、`assets/`（有就复制）和要用的位置 HTML **原样**复制进设计目录（HTML 可以改文件名，照常用英文小写）。**别重新手写外框**：页面里那段 `<template id="dsh-frame">` 是外框的指纹，体检靠它查外框有没有被改。
2. **只写槽位里面**：主体写进 `<div data-slot="main">`；别的槽位（标题、图标 …）照 `frame.json` 里的说明填。`<title>` 照常改成「屏名 · 产品名」，它不算外框。
3. **外框一个字都别动**：结构、文字、class、`style`、外框的样式文件、开头的 `<meta name="dsh-design">` 都不改，也别删外框里的东西。改了体检报「外框被改动」。
4. **样式只管槽位**：自己的样式写在 `<head>` 里自己的 `<style>`，每条选择器都从 `[data-slot="main"]` 开头。不写 `body`、`*`、`button`、`h1` 这种不带前缀的选择器——会改到外框。
5. **默认长得像外框**：外框的样式文件里有变量（`--` 开头）就用它们，深色跟着变；用户要自己的风格时才另建 `tokens.css`，也只在槽位里用。
6. 一个位置一屏；几屏的标题、图标要一致。

## 做外框

库里没有、用户给了截图或说明（「照这张截图做个 Chrome 插件弹窗的外框」）：先做外框、存进库，再用它出设计。

1. **建一个外框文件夹**（不是设计目录，比如工作区里的 `frames-src/<id>/`），里面放：
   - `frame.json`：
     ```json
     {
       "id": "chrome-popup",
       "name": "Chrome 插件弹窗",
       "nameEn": "Chrome extension popup",
       "desc": "浏览器右上角点插件图标弹出来的那块，连着一截浏览器工具栏",
       "size": [460, 640],
       "css": ["frame.css"],
       "frames": [
         { "id": "popup", "file": "popup.html", "name": "弹窗", "slots": { "icon": "工具栏上的插件图标，16×16", "main": "弹窗内容，400×560" } }
       ]
     }
     ```
     `id` 只用小写字母、数字和连字符（`dsh` 不能用）；`size` 是整个画面多大（外框 + 槽位）；一个外框可以有几个位置（`frames` 里几项，最多 8 个），每个位置一个 HTML，共用 `css`。图、字体放 `assets/`。存库只复制 `css` 里写的、位置 HTML 和 `assets/`：`@import` 的样式也要写进 `css`（或放进 `assets/`），不然 `save_frame` 不存。
   - 每个位置的 HTML：最外层包住整个外框的元素写 `data-frame="<id>/<位置 id>"`（如 `data-frame="chrome-popup/popup"`），是 `<body>` 里面的一个 `<div>`（别写在 `<html>`、`<body>` 上），铺满整个画面；外框不放脚本（`<script>`、`onclick`），只放固定的样子；要留给设计的地方写 `data-slot="名字"`，**必须有 `main`**，槽位并排、不能套在槽位里面，名字和 `frame.json` 的 `slots` 一一对上。槽位里留空，或者放一句灰字占位。
2. **照截图量准**：尺寸、颜色、字号、圆角、间距都照截图；外框里的字用占位（「我的账号」「示例网站」），**别放真实的人名、手机号、账号**。颜色写成样式文件里的变量（`--frame-bg` 这种），有深色就在 `[data-theme="dark"]` 下面给深色值。外框的样式选择器都带外框自己的 class，别写 `body`、`*`；页面边上的白边用 `<body style="margin:0">` 去掉。
3. **存进库**：调 `save_frame`（`dir` 写这个文件夹）。它检查槽位对不对、算指纹、截浅色 / 深色图回给你：对照截图看一遍，不像就改了再存（同 id 覆盖）。
4. **再用它出设计**：照上面「用外框」从库里复制（`save_frame` 返回的目录），类型标记已经写好了（`framed 宽x高`）。

## 讲究

- 不要在槽位里再画一遍外框已经有的东西（标题栏、工具栏、侧栏）。
- 槽位里的弹窗、下拉菜单也画在槽位里面（`position: absolute`），不要盖到外框上。
- 外框只防「不小心改到」：体检报「外框被改动」就重新从库里复制外框，再把槽位里的内容放回去。
