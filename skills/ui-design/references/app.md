# App 界面（kind: app）· 平板（kind: tablet）

## 画幅

- 手机按 390×844（iPhone 15/16）设计，页面宽度跟着视口走（`width: 100%`），不要居中一个小盒子。`<meta name="viewport" content="width=device-width,initial-scale=1">`。别写死 `width: 390px`、也别给 body 加 `max-width` 再居中：工作台已经按 390 宽显示、套好手机外框，多尺寸视图还会拿 375 / 430 宽来看，写死就露馅。也别为了这个另开浏览器截图——要检查就调 `check_design`。
- 顶部 54px 是状态栏 + 灵动岛：自己画一条状态栏（时间 9:41、信号、电量），中间空着——灵动岛预览的外框会画，页面里别再画一个（不然换尺寸看时会出现两个）。内容从 54px 以下开始。
- 底部 34px 是横条（home indicator）区：底部的标签栏 / 按钮要把它让出来（标签栏总高约 83px）。
- 左右边距 16–24px；卡片之间 12–16px。

## 结构和组件

- **导航**：主要页面用底部标签栏（3–5 个，图标 + 文字，当前项用主色）；层级页面顶部是返回 + 标题 + 右侧操作。大标题样式（34px 粗体，滚动后收成 17px 居中）适合一级页面。
- **触控**：可点的东西至少 44×44；主按钮高 50–56，圆角 12–16，通常放在拇指够得到的下半屏，长页面用底部固定操作栏。
- **列表**：行高 56–72；左侧图标 / 头像，中间两行字（标题 + 灰色说明），右侧值或箭头。分组列表用浅色背景分组，不用到处画线。
- **表单**：一行一个字段，标签在上，输入框高 48–56；键盘类型对应（手机号、验证码）。
- **反馈**：轻提示（toast）在顶部或底部中间，2 秒消失；危险操作二次确认用底部弹出的操作表（action sheet）。
- **空状态**：一张简单插画 + 一句说明 + 一个按钮，不要只写「暂无数据」。

## 多屏一致

一套 App 的几屏要像同一个产品：同一个标签栏（只是当前项不同）、同样的顶部栏、同样的卡片和按钮样式、同一套图标。把这些放进共用的 `app.css`（配合 `tokens.css`），每屏只写自己特有的部分。常见的一套：启动 / 登录 → 首页 → 列表或分类 → 详情 → 购物车或表单 → 结果或订单 → 我的。

## 平台风格

- 默认按 iOS 的感觉做（SF 风格字体栈、大标题、毛玻璃标签栏可以有但别滥用）。
- 用户说安卓 / Material：顶部栏 64px、悬浮按钮（FAB）、卡片圆角 12、涟漪反馈的意思到了就行。

## 平板（kind: tablet）

820×1180 竖屏；用两栏（左侧列表 320–360px + 右侧详情）或侧边导航，而不是把手机界面放大。字号和手机一样，不要跟着放大。
