# 海报 / 社媒图（kind: poster）

## 画幅

- 默认 1080×1350（4:5，朋友圈 / 小红书 / Instagram 竖图）。常用：1080×1920（9:16 竖版 / 开屏 / 故事）、1080×1080（方图）、1242×1660（小红书 3:4）。用别的尺寸时 `<meta name="dsh-design" content="poster 1080x1920">`，调 `preview_page` 时也带 `size`。
- `html, body` 宽高写死成画幅尺寸，`overflow: hidden`，不要滚动。内容放在四边各 64–80px 的安全区里。

## 构图

- **一个焦点**：一张主视觉（插画、产品、超大字）占画面 40–60%。
- **超大标题**：标题字号 96–160px，粗体，字距收紧（-0.03em），最多两行；副标题 32–40px；其他信息 24–28px。三档字号，拉开对比。
- **网格**：按 4 栏或 6 栏对齐，所有元素左边缘对齐同几条线；重要信息放在视线路径（左上 → 右下，或上 → 下居中）。
- **配色**：一个主色大面积 + 一个对比色点睛 + 黑白。背景可以是主色铺满，文字反白。
- **层次**：前景（文字）、中景（主视觉）、背景（色块 / 纹理）三层，适度重叠显得有设计感。
- **信息块**：时间、地点、价格、二维码位置这些放在底部一条信息带里，整齐排好。

## 做法

- 主视觉用 SVG 画（几何、插画、渐变网格），或用 CSS 形状、大字本身做视觉；不引用外网图片。
- 文字用真实文案；营销海报一定有明确的行动（扫码、日期、价格）。
- 一张海报多个版本（不同配色 / 版式）时，每个版本一个文件放同一目录，画布上并排比较。
