# 桌面软件（kind: desktop）

## 画幅

- 按 1280×800 设计（窗口里面那块），宽高都跟着视口走（`width: 100%`、整页 `height: 100vh`）：多尺寸视图还会拿 1024×680、1440×900 来看。每屏 `<head>` 写 `<meta name="dsh-design" content="desktop">`；做 Windows 软件写 `content="desktop windows"`（不写是 Mac）。
- **窗口按钮是外框画的**，盖在页面上面，页面里别再画：
  - Mac：左上角红绿灯，三个 12px 圆点在 x 20–72、y 20–32。顶部 52px 是工具栏（标题栏和工具栏合一），红绿灯在它左边；有侧栏时红绿灯压在侧栏顶上，侧栏顶部空出 52。标题、搜索、按钮放工具栏里、x 80 以后。
  - Windows：右上角最小化 / 最大化 / 关闭，共 138×32。顶部 32–48px 标题栏：左边应用图标 + 名字，右边空出 138。
  - 这两块别放字和按钮，体检会报「被窗口按钮挡住」。顶栏是深色时，Windows 的按钮自动画白的（判断不准就在 `<head>` 加 `<meta name="dsh-capsule" content="white">` 或 `black`）。
- Mac 的菜单栏在屏幕最上面、不在窗口里，别画；Windows 传统软件可以在标题栏下画一行菜单（文件 编辑 视图…）。

## 结构和组件

- **布局**：左侧栏（220–260，导航、文件夹、账户）+ 主区；要看列表和内容就三栏：侧栏 + 列表（280–360）+ 详情。栏之间 1px 分隔线，侧栏底色比主区略深或半透明。
- **整个窗口不滚**：侧栏、列表、详情各自滚（`overflow: auto`），工具栏和底部状态栏（可选，24px）一直在。
- **比手机密**：正文 13px（Mac）/ 14px（Windows），说明 11–12px；列表行高 28–36，按钮、输入框高 28–32，工具栏图标按钮 28×28；鼠标用，不用 44 的点击区。
- **桌面的规矩**：悬停有反馈（行变浅色底）；选中行用主色底或主色左边条；常用操作在菜单项右边写快捷键（Mac `⌘N`，Windows `Ctrl+N`）；右键菜单、多选、拖拽排序这类可以画出来。
- **弹窗**：Mac 的 sheet 从工具栏下面滑出，按钮在右下「取消 / 好」（默认按钮主色）；Windows 对话框按钮在右下「确定 / 取消」。设置页用侧边分组 + 右边表单，不用一屏一个。
- **空状态、首次打开**：一张简单插画 + 一句说明 + 一个主按钮（「新建文档」）。

## 平台风格

- Mac（默认）：`-apple-system, "SF Pro Text", "PingFang SC", sans-serif`；圆角 6–10，控件浅灰底，强调色只给选中和主按钮；侧栏可以半透明（`backdrop-filter`）。
- Windows 11：`"Segoe UI Variable", "Segoe UI", "Microsoft YaHei UI", sans-serif`；窗口底浅灰（云母）、卡片白底、圆角 4–8，主按钮实色，图标线条风格。
